# 汎用デモ(1ページ)の使い方

見本URL:https://umemura-raisecolor.github.io/proposals/sample/

## 営業先ごとに作るとき
1. `sample` フォルダをコピーして `/会社名(英字)/` を作る
2. 社名・電話・住所・許可番号・代表者名・創業年(カウントアップの数字)を、その会社のものに差し替える
3. **写真は、その会社のHPに使える写真があれば必ず入れる**(施工実績・代表の顔・職人さん・社屋など)
   - ファーストビューの流れる写真、施工実績、選ばれる理由、代表メッセージの順に優先して差し替える
   - 足りない部分だけ `img/` の素材写真を残す
4. 「写真・文章はすべてサンプルです」の注意書きは、その会社の写真を使った場合「掲載写真は、〇〇様の現在のホームページから使用しています」に変える
5. 型(レイアウト・色・動き)は崩さない
