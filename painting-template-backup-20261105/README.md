# RAISECOLOR 塗装会社向けテンプレート

フォルダをコピーし、会社ごとに company.js を編集してください。HTML の編集やビルドは不要です。index.html はローカルでも開けます。

- name / roman / logo / headline / intro / region に会社情報を設定
- strengths と guarantee に確認済みの強み・保証条件を設定。不明な保証は空欄
- projects の after に利用許諾のある画像を指定。before に同じ視点の施工前写真を指定すると、スライダー比較が表示される
- hero / craft / detail の写真を差し替え、imageNote / worksNote と必要に応じて画像の代替テキストを合わせる
- colors は6桁の16進数。変更後は文字のコントラストを確認
- 営業デモでは demo:true を維持し、実在企業用の demoLabel は「○○様向けの提案 · 公式サイトではありません」とする。電話とフォームの実送信導線はデモで表示しない
- 正式運用の際は demo:false とし、確認済みの phone / inquiry を指定。検索掲載が必要な場合は公開担当者が robots 設定とメタ説明を見直す

同梱の WebP 4枚は生成したイメージで、実在企業の施工実績・職人を示さない。第三者サイトの素材は同梱していない。公開デモは noindex を指定しているが、URL を知っている人は閲覧できる。

## CRM

実在企業向けのデモは、公開ページを確認した後、既存「デモサイト」タブの企業IDとデモURLを対応させる。新しいデモの制作・公開は営業送信と別に扱い、送信日は実際に案内した場合のみ記録する。アクセス解析を追加する場合は公開URLのホストとパスで照合し、計測IDを設定する。未計測の値は空欄のまま。架空サンプルは既存企業に紐付けない。
