# IMPACT(全画面カルーセルの型・紺×ゴールド)

ファーストビューで「あっ」と思わせるための型です。フォルダ名が「_」で始まるので、このフォルダ自体は公開されません。
見本(特定の会社ではない汎用デモ・〇〇塗装):https://umemura-raisecolor.github.io/proposals/tpl/impact/

## 見た目は2種類(site.js の theme で切り替え)
- `white`:白基調。斜めに切った大きな写真パネル、奥にのぞく紺のブロック、紺×ゴールドの色の帯が写真を横切って切り替わる(いまの見本)
- `navy`:紺の全画面に写真

## 入っている動き
- 開いた瞬間、社名の英字が浮かび、紺の幕が上下に割れて写真が現れる(1回だけ)
- 全画面の写真が、金の斜めの光と一緒に右からシャッと切り替わる(6.5秒ごと、ゆっくりズーム)
- 写真にまたがる巨大な英字(1行目は白、2行目は金の線文字)が一文字ずつ下から立ち上がる。マウスに合わせてわずかに動く
- 日本語キャッチは2行、下から現れる。{ } の部分はゴールド
- 右下に写真のサムネイルと進み具合のバー(クリックで切り替え、スマホはスワイプ)
- 一番下に工事の種類が流れつづける帯
- 見積りボタンに斜めの光がキラッと走る
- その下:数字のカウントアップ → 施工事例(つまみで施工前・施工後を見比べ)→ 選ばれる理由 → 代表あいさつ → 工事の内容 → ご依頼の流れ → 会社概要 → お問い合わせ
- スマホではスクロールすると画面下に「電話で相談/無料見積り」の固定ボタン

## 新しい営業先に使うとき
1. このフォルダの index.html と site.js を `/会社名(英字)/` にコピー
2. `site.js` だけ書き換える(index.html は触らない)
   - 社名・電話・エリア、写真3〜5枚(相手の今のHPから)、英字とキャッチ
   - 数字4つ(料金・値段は入れない)、施工事例(施工前・施工後の写真)、理由3つ、代表の顔写真とあいさつ、工事の内容、会社概要
   - 写真が少ない・粗い会社は、素材写真で埋める
3. 公開URL:https://umemura-raisecolor.github.io/proposals/会社名/

## 素材写真
img フォルダの写真(外壁・屋根の家3軒、職人の作業、点検、色選び、防水)は汎用の素材です。施工前の写真(-before)は施工後の写真を色あせ加工したものなので、見本専用です。
