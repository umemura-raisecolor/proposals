# ファーストビューの型(紺×ゴールド)

営業先ごとのデモHPのトップに使う、目を引くファーストビューの型です。
フォルダ名が「_」で始まるので、このフォルダ自体は公開されません。

## 入っている動き
- 右半分に建物の写真(斜めカット+ゴールドの線)、左の背景にも同じ写真がうっすら
- 写真は6.5秒ごとにゆっくりフェードで切り替わり、表示中はじわっとズーム
- すりガラスのパネルに、キャッチコピー3行(2行目がゴールド)・説明文・ボタン2つ
- 文字は上から一行ずつふわっと表示、見積りボタンには斜めの光がキラッと走る
- 右下に、いま映っている施工事例の名前と切り替えバー
- 大きな数字の帯:0からカウントアップして、止まった瞬間にポンと弾む
  (料金・値段はカウントアップさせない)

## 新しい営業先に使うとき
1. このフォルダの中身(index.html と site.js)を `/会社名(英字)/` にコピー
2. `site.js` だけを書き換える(index.html は触らない)
   - 会社名・電話・メニュー・キャッチコピー・説明文・ボタン
   - 写真3枚(相手の今のHPの施工写真)と、その下に出す名前
   - 数字4つ(創業からの年数、職人・スタッフ数、施工実績数など)
3. 公開URL:https://umemura-raisecolor.github.io/proposals/会社名/

## 色
ふだんは紺×ゴールド。会社に合わせて変えたいときだけ、site.js の最後の `colors` を使います。
赤系の差し色は使わない方針です。
